### Join AddVenture
We can pick more agents to perform one mission, either pick several agent for mission, or attach extra agents to main agent. Each agent can perform 1 task per turn. 

### Testing 
When we test we sum 2 best values in agent participants. So taking more than 2 agents is overkill, unless it is complex mission with several rolls. 
**Damage** we suffer only 1dmg at time, and it is dealt at random among participants. 
**Busted** 1 agent at random is jailed
**Recruit** Extra agents has Recruit keyword, so to unlock them first need to complete recruit mission. Recruit mission could be completed once and it is gone from pool.  
If our fresh agents got killed later, too bad, take care more next time.
**Rested** We get only 1 dice of rest bonus. Actually change rest bonus to 1 dice. And our rested character needs to be among 2 chosen for test.
